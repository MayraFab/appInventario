# appInventario – Panel Administrativo (Frontend)

Panel de inventario en **React 19 + Vite + React Router + Axios + Bootstrap 5** que consume la API de
[appApi](https://github.com/MayraFab/appApi) (Laboratorios #8 y #9 – Seminario IA 502, SENATI).

## Vistas
Login (JWT) · Dashboard (KPI y gráfico) · Productos · Categorías · Proveedores · Kardex / Movimientos · Usuarios

## Ejecutar
```bash
npm install
npm run dev     # http://localhost:5173  (el backend debe estar en http://localhost:3006)
```
